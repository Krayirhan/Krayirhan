### 👋 Ben Kimim?

Merhaba, ben **Furkan** — tek başına ürün fikrini alıp **mobil uygulamaya, web SaaS'a veya makine öğrenmesi çözümüne** dönüştürmeyi seven bir yazılım geliştiriciyim.
